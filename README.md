# Insurance Claims & Fraud Analysis Dashboard

## Project Overview
This project analyzes insurance claims, settlement amounts, and fraud risks. It demonstrates my workflow of using AI for data validation in Excel, followed by interactive dashboard creation in Power BI.

## Tools Used
- **Excel:** Data cleaning and AI-assisted validation.
- **Power BI:** Data visualization and DAX.
- **AI (ChatGPT):** Used to generate Excel formulas for data checking.

## Key Features
- **KPI Cards:** Total Claim Amount, Settlement Amount, and Fraud Risk Score.
- **Ribbon Chart:** Tracks Policy Type across Claim Status.
- **Treemap:** Visualizes Claim Amount by Claim Type.
- **Scatter Chart:** Analyzes Credit Score vs. Claim Amount.
- **Slicer:** Filters data by Region.
